# آموزشگاه کنکور اوج — دموی سایت

یک دموی سایت آموزشگاهی کاملاً فارسی (RTL)، فقط با HTML / CSS / JS ساده — بدون هیچ فریمورک یا فرآیند بیلد، آماده‌ی دیپلوی روی GitHub Pages.

## ساختار پروژه
```
.
├── index.html            صفحه اصلی
├── about_us.html          درباره ما
├── courses.html           لیست دوره‌ها (با فیلتر ریاضی/تجربی/انسانی)
├── courses_detail.html    جزئیات یک دوره
├── teachers.html          اساتید
├── contact_us.html        تماس با ما (فرم دمو + نقشه)
└── static/
    ├── css/style.css      استایل مشترک تمام صفحات
    ├── js/main.js         منوی موبایل، فیلتر دوره‌ها، اعتبارسنجی فرم، شمارنده آمار
    └── img/               پوشه‌ی خالی برای عکس‌های واقعی شما
```

فونت فارسی از Google Fonts (Vazirmatn) بارگذاری می‌شه؛ برای مشاهده صحیح فونت به اینترنت نیاز دارید.

## دیپلوی روی GitHub Pages
1. یک ریپازیتوری جدید در گیت‌هاب بسازید و تمام فایل‌های این پوشه رو (با همین ساختار) داخلش push کنید.
2. وارد Settings → Pages بشید.
3. در بخش Source گزینه‌ی `Deploy from a branch` رو انتخاب کنید، شاخه‌ی `main` و پوشه‌ی `/ (root)` رو انتخاب و Save کنید.
4. بعد از چند دقیقه، سایت شما روی آدرسی شبیه این در دسترس خواهد بود:
   `https://<username>.github.io/<repo-name>/`

## نکات مهم
- تمام محتوا (آمار، اسامی اساتید، قیمت‌ها و غیره) صرفاً نمونه و برای دمو هست؛ قبل از استفاده واقعی جایگزینشون کنید.
- عکس واقعی ندارید؟ فایل‌های خودتون رو داخل `static/img/` بذارید و در HTML با `<img src="static/img/نام-فایل.jpg">` صداشون بزنید. آواتارهای فعلی (حروف داخل دایره) صرفاً جایگزین موقت‌اند.
- نقشه‌ی صفحه‌ی تماس یک embed عمومی گوگل‌مپ روی «تهران» است؛ آدرس دقیق خودتون رو در URL آیفریم داخل `contact_us.html` جایگزین کنید.
- فرم تماس فقط سمت کلاینت اعتبارسنجی می‌شه و به هیچ سروری وصل نیست (GitHub Pages فقط فایل استاتیک سرو می‌کنه). برای ارسال واقعی ایمیل، از سرویس‌هایی مثل Formspree یا Netlify Forms استفاده کنید یا بک‌اند اختصاصی بسازید.
